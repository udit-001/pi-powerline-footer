# pi-powerline-footer

Powerline-style status bar for [pi](https://github.com/earendil-works/pi-coding-agent). Shows model, thinking level, git, tokens, and usage in the editor border.

## Install

```bash
pi install git:github.com/udit-001/pi-powerline-footer
```

## Use

Activates automatically.

- `/powerline` — toggle on and off
- `/powerline <preset>` — switch preset

Presets: `default`, `minimal`, `compact`, `full`, `nerd`, `ascii`.
